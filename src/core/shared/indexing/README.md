# Indexing 模組

## 主要功能

高效能程式碼索引系統，提供毫秒級查詢能力：

- **檔案索引**：建立檔案元資料快取，支援快速檔案查找
- **符號索引**：索引所有程式碼符號（函式、類別、變數等），支援語義搜尋
- **增量更新**：監控檔案變更，自動增量更新索引
- **批次建構**：高效處理大型專案，1000 檔案/秒索引速度

## 使用情境

- **符號搜尋**：IDE 功能的基礎，支援「跳轉到定義」、「查找引用」
- **語義分析**：為重構、重命名等功能提供符號資訊
- **專案掃描**：快速定位特定符號或程式碼模式
- **即時反饋**：監控檔案變更，自動更新索引狀態

## 核心類別

- `IndexEngine`：索引引擎主控制器
- `FileIndex`：檔案索引管理
- `SymbolIndex`：符號索引管理
- `FileWatcher`：檔案變更監控器

## 效能指標

- 索引速度：1000+ 檔案/秒
- 查詢延遲：< 10ms
