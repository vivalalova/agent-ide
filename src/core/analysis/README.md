# Analysis 模組

## 主要功能

程式碼品質評估與分析模組，提供以下核心能力：

- **品質指標分析**：評估程式碼的可維護性、複雜度、可讀性等多維度品質指標
- **可維護性指數**：計算 Maintainability Index (MI)，量化程式碼的長期維護成本
- **Code Smell 檢測**：自動識別常見的程式碼異味，如過長函式、重複代碼、過度耦合等

## 使用情境

- **程式碼審查**：自動化評估 Pull Request 的程式碼品質
- **技術債務評估**：量化專案的技術債務，制定重構優先級
- **品質趨勢追蹤**：定期分析專案品質變化，預防品質劣化
- **開發指導**：為開發者提供即時的程式碼品質反饋

## 核心類別

- `QualityMetricsAnalyzer`：品質指標分析器
- `MaintainabilityIndex`：可維護性指數計算
- `CodeSmellDetector`：Code Smell 偵測器
