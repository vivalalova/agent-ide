# Search 模組

## 主要功能

多模式程式碼搜尋引擎，支援多種搜尋策略：

- **文字搜尋**：基於正則表達式的全文搜尋
- **語義搜尋**：基於程式碼語義的智慧搜尋
- **結構化搜尋**：根據 AST 結構搜尋特定程式碼模式
- **符號搜尋**：精確查找符號定義與引用

## 使用情境

- **程式碼定位**：快速找到特定函式、類別或變數
- **模式識別**：搜尋符合特定模式的程式碼片段
- **重構準備**：找到所有需要修改的程式碼位置
- **程式碼審查**：搜尋潛在的問題模式或反模式

## 核心類別

- `SearchService`：搜尋服務主入口
- `TextSearchEngine`：文字搜尋引擎

## 支援功能

- 正則表達式搜尋
- 大小寫敏感選項
- 檔案類型過濾
- 結果排序與分頁
