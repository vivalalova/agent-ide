# Rename 模組

## 主要功能

符號重命名與引用更新模組，提供安全的重命名能力：

- **符號重命名**：重命名變數、函式、類別、介面等程式碼元素
- **引用查找**：精確查找符號的所有引用位置
- **作用域分析**：分析符號作用域，避免命名衝突
- **批次重命名**：支援多個符號的批次重命名操作
- **衝突檢測**：預先檢測命名衝突與 shadowing 問題

## 使用情境

- **命名改善**：改善不清晰的變數或函式名稱
- **重構支援**：在重構過程中安全地重命名符號
- **統一命名**：統一專案內的命名規範
- **API 重構**：重命名 public API 並更新所有使用處

## 核心類別

- `RenameEngine`：重命名主引擎
- `ScopeAnalyzer`：作用域分析器
- `ReferenceUpdater`：引用更新器

## 支援功能

- 跨檔案重命名
- 預覽模式
- Rollback 機制
