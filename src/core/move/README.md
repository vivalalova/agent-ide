# Move 模組

## 主要功能

檔案移動與 Import 路徑自動更新模組：

- **檔案移動**：安全地移動檔案或目錄到新位置
- **Import 自動更新**：自動更新所有受影響檔案的 import/export 路徑
- **路徑解析**：智慧解析相對路徑、絕對路徑、alias 路徑
- **衝突檢測**：預先檢測路徑衝突與潛在問題
- **預覽模式**：顯示變更影響範圍，支援決策

## 使用情境

- **專案重構**：調整目錄結構時自動維護 import 正確性
- **模組遷移**：將模組移動到新位置，無需手動修改引用
- **程式碼組織**：重新組織檔案結構，提升專案可讀性
- **團隊協作**：減少移動檔案導致的 merge conflict

## 核心類別

- `MoveService`：移動操作主服務
- `ImportResolver`：Import 路徑解析與更新

## 支援功能

- 批次移動
- Rollback 機制
- 路徑驗證
