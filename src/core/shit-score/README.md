# ShitScore 模組

## 主要功能

程式碼品質評分系統，提供 0-100 分的垃圾度評分：

- **多維度評分**：從複雜度、可維護性、架構、品質保證四個維度評估
- **評級系統**：S/A/B/C/D/F 六級評分，直觀呈現程式碼品質
- **問題識別**：自動識別並分類程式碼問題
- **改善建議**：提供具體的程式碼改善建議

## 評分維度

1. **Complexity (30%)**：圈複雜度、認知複雜度、巢狀深度
2. **Maintainability (30%)**：函式長度、重複代碼、文件完整度
3. **Architecture (30%)**：依賴關係、模組耦合度、設計原則遵循
4. **Quality Assurance (20%)**：型別安全、測試覆蓋率、錯誤處理、命名規範、安全性

## 使用情境

- **專案評估**：量化專案整體程式碼品質
- **技術債追蹤**：定期評分追蹤技術債變化
- **重構優先級**：根據評分決定重構順序
- **團隊標準**：建立團隊程式碼品質基準

## 核心類別

- `ShitScoreAnalyzer`：評分分析器
- `ScoreCalculator`：分數計算器
- `Grading`：評級系統
