# Shift 模組

## 主要功能

行級程式碼移動與檔案生成模組，提供精細的程式碼搬移能力：

- **行內移動**：在同一檔案內移動程式碼行
- **跨檔案移動**：將程式碼行移動到其他檔案
- **新檔案生成**：將程式碼提取到新建立的檔案
- **依賴分析**：自動分析移動程式碼的依賴關係
- **Import 更新**：自動調整 import 語句

## 使用情境

- **程式碼重組**：將相關程式碼移動到同一位置
- **模組拆分**：將大檔案拆分為多個小模組
- **關注點分離**：將不同關注點的程式碼分離到不同檔案
- **測試組織**：將測試程式碼移動到對應的測試檔案

## 核心類別

- `ShiftService`：移動服務主控制器
- `LineExtractor`：行提取器
- `FileGenerator`：檔案生成器

## 支援操作

- 單行移動
- 多行移動
- 條件式移動
