# Dependency 模組

## 主要功能

依賴關係分析與管理模組，提供專案依賴圖的完整分析能力：

- **依賴圖建構**：建立完整的檔案與模組依賴關係圖
- **循環依賴檢測**：使用 Tarjan 演算法檢測強連通元件（SCC），識別循環依賴
- **影響分析**：基於 BFS 分析修改檔案的影響範圍
- **拓撲排序**：計算模組載入順序，支援依賴優先的建構流程

## 使用情境

- **重構規劃**：分析修改影響範圍，降低重構風險
- **架構清理**：識別並解決循環依賴，改善專案結構
- **模組拆分**：分析模組耦合度，指導模組邊界設計
- **建構優化**：計算最優建構順序，提升編譯效率

## 核心類別

- `DependencyAnalyzer`：依賴分析主引擎
- `DependencyGraph`：依賴圖資料結構
- `CycleDetector`：循環依賴偵測器
