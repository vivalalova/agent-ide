# Snapshot 模組

## 主要功能

程式碼快照生成與壓縮模組，為 AI 模型提供最佳化的專案上下文：

- **快照生成**：建立專案結構、符號、依賴關係的完整快照
- **智慧壓縮**：最小化 token 使用，最大化資訊保留
- **增量更新**：支援增量快照，只記錄變更部分
- **Diff 分析**：比較快照差異，生成變更報告

## 使用情境

- **AI 上下文**：為 AI 模型提供專案完整上下文
- **專案文檔**：生成專案結構與 API 文檔
- **變更追蹤**：追蹤專案演進歷史
- **Code Review**：快速了解 PR 影響範圍

## 核心類別

- `SnapshotEngine`：快照生成引擎
- `CodeCompressor`：程式碼壓縮器
- `SnapshotDiffer`：快照差異分析
- `ConfigManager`：配置管理器

## 壓縮等級

- Minimal：最小壓縮
- Moderate：中度壓縮
- Aggressive：最大壓縮
