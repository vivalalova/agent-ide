# CLI 功能評比

檢查本專案所有 CLI 功能，產出兩份評比表格到 `todo/` 目錄。

## 任務

### 1. 閱讀所有 CLI 命令
掃描 `src/interfaces/cli/commands/` 下所有命令實作，理解每個功能的：
- 輸入參數
- 輸出格式
- 核心用途

### 2. 產出評比表格

#### 表格一：現有功能評比
檔案：`todo/cli-evaluation-current.md`

對每個現有 CLI 命令評分（1-5 星），評分項目：

| 項目 | 說明 |
|------|------|
| AI 友善輸出 | JSON 結構化、資訊完整度 |
| Token 節省 | 相比 AI 手動操作節省多少 token |
| 比手動快 | 執行速度、操作步驟減少 |
| 對 AI 有意義 | AI 代理實際使用場景價值 |
| 可行性 | 實作難度、維護成本、技術風險 |

產出格式：

- 總評表（所有命令一覽，**依總分高到低排序**）
- 每個命令的詳細分析
- 分級建議（A+/A/B/C/D）

#### 表格二：新功能建議
檔案：`todo/cli-evaluation-proposals.md`

想出 10 個適合加入的新功能，同樣用五個項目評分，**依總分高到低排序**，包含：

- 功能名稱與說明
- CLI 語法範例
- 預期輸出格式
- 實作複雜度評估
- 與現有功能的對比
- **實作原理**（簡要說明核心算法或技術方案）

### 3. 產出摘要

在兩份檔案最後加入：

- 移除候選（C 級以下）
- 新增候選（A 級以上）
- 優先實作順序建議
